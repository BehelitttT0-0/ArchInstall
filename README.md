# Minimal BSPWM для Arch Linux

Скрипт автоматической установки минималистичного монохромного рабочего стола на «голом» Arch Linux.

**Состав системы:** BSPWM + sxhkd + Alacritty + Fish + Rofi + Polybar + Dunst + Picom.

- Чёрно-белая цветовая схема во всех компонентах.
- Тайлинговый оконный менеджер BSPWM, всё управление с клавиатуры.
- Прозрачность терминала Alacritty (Picom используется только для неё: без теней, размытия и анимаций).
- Раскладки `us` / `ru`, переключение по `Super + Space`.
- Полоса Polybar с рабочими столами, часами, нагрузкой CPU, RAM, GPU и VRAM.
- Автозапуск графической сессии сразу после входа в TTY1, без ввода `startx`.
- Драйверы под видеокарту AMD Radeon RX 5600 XT (открытый стек AMDGPU / Mesa).

---

## Что делает скрипт

1. Проверяет, что он запущен на Arch Linux, от обычного пользователя (не от root) и что доступны `sudo` и `pacman`.
2. Обновляет систему и устанавливает пакеты: Xorg, BSPWM, sxhkd, Alacritty, Fish, PCManFM, Firefox, Rofi, Feh, Polybar, Dunst, Picom, NetworkManager, PipeWire, VS Code, btop, fastfetch, шрифты и драйверы AMD.
3. Устанавливает AUR-помощник `yay` (из пакета `yay-bin`).
4. Делает Fish оболочкой по умолчанию.
5. Включает `NetworkManager` и аудиосервер PipeWire.
6. Записывает конфигурационные файлы в `~/.config/`, а также `~/.xinitrc`.
7. Настраивает автозапуск X11 после входа в систему на TTY1.

> ⚠️ **Внимание:** конфиги записываются напрямую, **без резервных копий**. Если у тебя уже есть собственные настройки в `~/.config/bspwm`, `sxhkd`, `alacritty`, `fish`, `rofi`, `polybar`, `dunst`, `picom` или файл `~/.xinitrc`, они будут перезаписаны.

## Установка с нуля (на чистом Arch Linux)

Предполагается, что у тебя уже установлен минимальный Arch Linux (например, через `archinstall` или вручную по [Installation guide](https://wiki.archlinux.org/title/Installation_guide)): есть ядро, загрузчик, работает загрузка в консоль (TTY), и ничего графического ещё не стоит.

### 1. Войди в систему

Загрузись в установленный Arch и войди в консоль. Если у тебя пока только root, создай обычного пользователя (шаг 2).

### 2. Создай обычного пользователя с правами sudo

Скрипт **нельзя запускать от root** и **нельзя запускать через `sudo`**: он сам вызывает `sudo` там, где это нужно, а конфиги должны попасть в домашний каталог обычного пользователя.

Выполни от root:

```bash
pacman -S --needed sudo nano
useradd -m -G wheel -s /bin/bash имя_пользователя
passwd имя_пользователя
EDITOR=nano visudo
```

В открывшемся файле найди и раскомментируй (убери `#`) строку:

```
%wheel ALL=(ALL:ALL) ALL
```

Сохрани (`Ctrl + O`, `Enter`) и выйди (`Ctrl + X`). Затем выйди из root (`exit`) и войди под новым пользователем.

### 3. Подключись к интернету

Если используется проводное соединение, обычно всё работает сразу. Проверь:

```bash
ping -c 3 archlinux.org
```

Для Wi-Fi можно подключиться через `iwctl`:

```bash
iwctl
[iwd]# station wlan0 scan
[iwd]# station wlan0 get-networks
[iwd]# station wlan0 connect НАЗВАНИЕ_СЕТИ
[iwd]# exit
```

(Имя интерфейса `wlan0` может отличаться, посмотри его командой `iwctl device list`.)

После установки скрипта сетью будет управлять NetworkManager (`nmtui` или `nmcli`).

### 4. Установи git и скачай репозиторий

```bash
sudo pacman -S --needed git
git clone https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПОЗИТОРИЙ.git
cd ТВОЙ_РЕПОЗИТОРИЙ
```

### 5. Запусти скрипт

```bash
chmod +x install-bspwm-minimal.sh
./install-bspwm-minimal.sh
```

Скрипт спросит подтверждение (`Продолжить? [y/N]`), введи `y`. Дальше он попросит пароль `sudo`, а при установке `yay` может запросить его ещё раз. Установка занимает несколько минут, зависит от скорости интернета.

### 6. Перезагрузись

```bash
reboot
```

Перезагрузка нужна, чтобы применилась смена оболочки на Fish, запустились сервисы и подгрузились драйверы.

### 7. Войди в систему

После перезагрузки на TTY1 появится приглашение:

```
login: имя_пользователя
Password: ********
```

После успешного ввода логина и пароля графическая сессия **запустится автоматически**, вводить `startx` не нужно. Ты увидишь BSPWM с панелью Polybar сверху.

Нажми `Super + Enter`, чтобы открыть терминал.

## Как работает автозапуск X11

Автозапуск делается в `~/.config/fish/config.fish`:

```fish
if status is-login
    if test -z "$DISPLAY" -a "$XDG_VTNR" = "1"
        exec startx
    end
end
```

- Срабатывает только при входе в систему (login-шелл), а не при каждом открытии терминала.
- Работает только на **TTY1**. На TTY2–TTY6 остаётся обычная консоль, это пригодится, если сломаешь конфиг: переключись на `Ctrl + Alt + F2`, войди и исправь.
- После выхода из BSPWM (`Super + Shift + Q`) ты вернёшься на экран логина.

Чтобы X запускался на любом TTY, убери условие `-a "$XDG_VTNR" = "1"`.

## Видеокарта

Скрипт настроен под **AMD Radeon RX 5600 XT** и ставит пакеты `linux-firmware-amdgpu`, `mesa`, `vulkan-radeon`, `libva-mesa-driver`. Загрузка GPU и объём VRAM в Polybar читаются из sysfs драйвера `amdgpu`.

Если у тебя другая видеокарта:

- **AMD:** скорее всего, всё будет работать без изменений.
- **NVIDIA / Intel:** замени драйверные пакеты в массиве `packages` в начале скрипта, а модули `GPU` и `VRAM` в Polybar покажут `N/A` (либо убери их из `modules-right` в `~/.config/polybar/config.ini`).

## Структура конфигов

| Файл | Назначение |
|---|---|
| `~/.xinitrc` | запуск BSPWM через `startx` |
| `~/.config/bspwm/bspwmrc` | настройки BSPWM, автозапуск программ, раскладки |
| `~/.config/sxhkd/sxhkdrc` | горячие клавиши |
| `~/.config/alacritty/alacritty.toml` | терминал: шрифт, цвета, прозрачность |
| `~/.config/fish/config.fish` | оболочка Fish, алиасы, автозапуск X |
| `~/.config/rofi/config.rasi` | запуск приложений |
| `~/.config/polybar/` | панель (`config.ini`, `launch.sh`, `gpu.sh`) |
| `~/.config/dunst/dunstrc` | уведомления |
| `~/.config/picom/picom.conf` | композитор (только прозрачность) |

## Решение проблем

**После логина вместо графики остаётся консоль.**
Проверь, что ты вошёл именно на TTY1 (`Ctrl + Alt + F1`). Если не помогло, запусти вручную `startx` и посмотри на ошибки. Лог лежит в `~/.local/share/xorg/Xorg.0.log`.

**Не переключается раскладка.**
Переключение: `Super + Space`. Настраивается в `~/.config/bspwm/bspwmrc` (команда `setxkbmap`).

**Нет звука.**
Проверь, что запущены сервисы: `systemctl --user status pipewire pipewire-pulse wireplumber`. Громкость регулируется в `pavucontrol` (запуск через `Super + D`).

**Не работают горячие клавиши после правки конфига.**
Перезагрузи sxhkd: `Super + Escape`. Если не помогло, перезапусти BSPWM: `Super + Shift + R`.

**Нет сети после установки.**
Используй `nmtui` (текстовый интерфейс) или `nmcli device wifi connect НАЗВАНИЕ password ПАРОЛЬ`.

## Горячие клавиши

`Super` это клавиша Windows.

### Программы

| Сочетание | Действие |
|---|---|
| `Super + Enter` | Открыть терминал (Alacritty) |
| `Super + D` | Запуск приложений (Rofi) |
| `Super + E` | Файловый менеджер (PCManFM) |
| `Super + F` | Браузер (Firefox) |

### Управление окнами

| Сочетание | Действие |
|---|---|
| `Super + W` | Закрыть активное окно |
| `Super + M` | Включить / выключить полноэкранный режим |
| `Super + Shift + Space` | Переключить окно в плавающий режим и обратно |
| `Super + ←` `↓` `↑` `→` | Переместить фокус на соседнее окно в этом направлении |
| `Super + Shift + ←` `↓` `↑` `→` | Поменять активное окно местами с соседним |
| `Super + Ctrl + ←` `↓` `↑` `→` | Изменить размер окна: расширить в сторону стрелки |
| `Super + Alt + ←` `↓` `↑` `→` | Сдвинуть плавающее окно на 20 пикселей |

### Рабочие столы

| Сочетание | Действие |
|---|---|
| `Super + 1` ... `Super + 6` | Перейти на рабочий стол 1–6 |
| `Super + Shift + 1` ... `Super + Shift + 6` | Переместить активное окно на рабочий стол 1–6 |

### Мышь

| Сочетание | Действие |
|---|---|
| `Super + левая кнопка` (перетаскивание) | Переместить окно |
| `Super + средняя кнопка` (перетаскивание) | Изменить размер окна по ближайшей стороне |
| `Super + правая кнопка` (перетаскивание) | Изменить размер окна по ближайшему углу |

### Система

| Сочетание | Действие |
|---|---|
| `Super + Space` | Переключить раскладку клавиатуры (US / RU) |
| `Super + Escape` | Перезагрузить конфигурацию горячих клавиш (sxhkd) |
| `Super + Shift + R` | Перезапустить BSPWM (применить изменения в `bspwmrc`) |
| `Super + Shift + Q` | Выйти из BSPWM (возврат на экран логина) |

### Rofi (внутри меню запуска)

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | Выбор приложения |
| `Enter` | Запустить выбранное |
| `Esc` | Закрыть меню |
