# Minimal BSPWM для Arch Linux

Скрипт установки минималистичного монохромного рабочего стола на чистый Arch Linux.

**Состав:** BSPWM, sxhkd, Alacritty, Fish, Rofi, Polybar, Dunst, Picom.

- Чёрно-белая тема, управление с клавиатуры.
- Прозрачный терминал (Picom используется только для этого).
- Раскладки US / RU, переключение по `Super + Space`.
- Polybar показывает рабочие столы, время, CPU, RAM, GPU и VRAM.
- После входа в TTY1 X11 запускается сам, без команды `startx`.
- Драйверы под AMD Radeon RX 5600 XT (AMDGPU / Mesa).

## Требования

- Установленный минимальный Arch Linux с доступом в интернет.
- Обычный пользователь с правами `sudo`.
- Установленный `git`.

## Установка

```bash
git clone https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПОЗИТОРИЙ.git
cd ТВОЙ_РЕПОЗИТОРИЙ
chmod +x install-bspwm-minimal.sh
./install-bspwm-minimal.sh
```

Запускай от обычного пользователя, **не от root и не через `sudo`**: скрипт сам вызовет `sudo` там, где нужно.

После установки перезагрузись:

```bash
reboot
```

На TTY1 введи логин и пароль, и графическая сессия запустится автоматически.

> ⚠️ Конфиги записываются в `~/.config/` и `~/.xinitrc` **без резервных копий**. Существующие настройки будут перезаписаны.

## Что делает скрипт

1. Обновляет систему и ставит пакеты (Xorg, BSPWM, приложения, драйверы AMD).
2. Ставит AUR-помощник `yay`.
3. Делает Fish оболочкой по умолчанию.
4. Включает NetworkManager и PipeWire.
5. Записывает конфиги и настраивает автозапуск X11 на TTY1.

## Обои

Положи картинку в `~/Pictures/wallpaper.png` и перезапусти BSPWM (`Super + Shift + R`).

## Другая видеокарта

Для NVIDIA / Intel замени драйверные пакеты в массиве `packages` в начале скрипта. Модули GPU и VRAM в Polybar работают только с AMD, иначе будет `N/A`.

## Горячие клавиши

`Super` это клавиша Windows.

| Сочетание | Действие |
|---|---|
| `Super + Enter` | Терминал (Alacritty) |
| `Super + D` | Запуск приложений (Rofi) |
| `Super + E` | Файловый менеджер (PCManFM) |
| `Super + F` | Браузер (Firefox) |
| `Super + W` | Закрыть окно |
| `Super + M` | Полноэкранный режим |
| `Super + Shift + Space` | Плавающее окно вкл / выкл |
| `Super + ←↓↑→` | Фокус на соседнее окно |
| `Super + Shift + ←↓↑→` | Поменять окна местами |
| `Super + Ctrl + ←↓↑→` | Изменить размер окна |
| `Super + Alt + ←↓↑→` | Сдвинуть плавающее окно |
| `Super + 1…6` | Перейти на рабочий стол |
| `Super + Shift + 1…6` | Переместить окно на рабочий стол |
| `Super + Space` | Переключить раскладку US / RU |
| `Super + Escape` | Перезагрузить горячие клавиши (sxhkd) |
| `Super + Shift + R` | Перезапустить BSPWM |
| `Super + Shift + Q` | Выйти из BSPWM |

**Мышь:**

| Сочетание | Действие |
|---|---|
| `Super + ЛКМ` | Переместить окно |
| `Super + СКМ` | Изменить размер по стороне |
| `Super + ПКМ` | Изменить размер по углу |
